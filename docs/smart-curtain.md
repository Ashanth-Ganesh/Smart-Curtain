Primary UI components:
- Smartphone app
- Curtain display


The smartphone has the ability to control widgets and settings for the curtain.


Key features
1) Smarphone can switch between rooms (bedroom 1, bedroom 2, living room, kitchen, etc.)
2) Phone can control physical curtain contraction and retraction bot horizontally and vertically
3) App can customize widgets displayed on the curtain like weather, time, inside temperature, curtain translucensy, AI assistants, to-do/task lists, music and security feeds / custom displays
4) The app also allows users to draw shapes on to the curtain and change the background image of the section they drew or change the translusency/the amount of ligh allowed to pass through for that section. For exampe a user draws in the app and a circle appears in the window and the user sets the circle to be transparent like a window but the rest of the curtain to complete darkness. this allows users to pretty much turn their curtains into custom windows.
5) users can also upload custom images to display on the full curtain or the section they drew up.
6) The curtain also has pre-defined sections if a user does not want to draw. the predefined sections can be a simple 4x4 grid.
7) The app will also allow users to turn on some toggle that adjusts the translusency of the curtain dymanically using a light sensor so that the brighness inside the room remains constant to their preference. The light sensor itself does not have to be visible in the UI. Its more implied.
8) The app should have a tab that allows users to set their video feed widget to a specific video feed or GIF.
9) The curtain should ideally have animations for all actions liek opening/closing, and changing translusency.
